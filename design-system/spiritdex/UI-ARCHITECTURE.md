# SpiritDex UI 架构重设计方案

> 由 `ui-ux-pro-max` skill 生成 + 现状分析综合得出。方向:**强化游戏感**(Gaming 沉浸鲜艳),基底保留 Wiki 工具的清晰高效。
>
> 本文档是**架构方案**,不含代码改动。落地时按"迁移路径"分阶段执行。

---

## 一、设计理念

SpiritDex 是 **Gaming(游戏收藏)× Wiki(数据百科)** 的混合体。核心张力:

| 维度 | Gaming 诉求 | Wiki 诉求 | SpiritDex 取舍 |
|------|------------|-----------|----------------|
| 视觉 | 沉浸、鲜艳、有性格 | 清爽、中性、高可读 | **工具底 + 游戏点缀** |
| 信息 | 氛围感优先 | 信息密度优先 | 数据页重密度,首页/详情重氛围 |
| 动效 | 生动、有反馈 | 克制、不打扰 | 微交互丰富,页面切换克制 |

**一句话定位**:**像宝可梦图鉴 App 一样好玩的攻略工具站**——打开是精灵球红 + 属性色的鲜活感,查阅时是干净高效的数据表格。

## 二、设计令牌(Design Tokens)

### 2.1 色彩系统演进

#### 主色修正:精灵球红 → 洛克王国蓝(品牌一致性修正)

**这是品牌错误修正**——原主色 `#e84545` 是宝可梦精灵球红,但洛克王国的精灵球(咕噜球)标志色是**蓝色**。主色改为洛克王国 logo 的明亮天蓝 `#2E8DE0`,红色降级为收藏/danger 专用色。

```css
:root {
  /* 主色:洛克王国蓝(咕噜球标志色)— 修正原宝可梦红的品牌错误 */
  --primary: #2e8de0;
  --primary-hover: #1e78d0;       /* hover 加深 */
  --primary-foreground: #ffffff;
  --primary-glow: rgba(46, 141, 224, 0.4); /* 光晕(游戏感) */

  /* 收藏/danger 专用红(原主色降级) */
  --danger: #ef4444;              /* 已有,保持 */
  --favorite: #e84545;            /* 新增:收藏心心专用红 */
}
```

**联动改动**:`--ring`(focus 环)跟随 primary 改蓝。

> 注:此修正影响 logo 圆形背景、主 CTA 按钮、focus 环等所有 `bg-primary`/`text-primary` 用法。落地时全局搜索替换。

#### 属性色(核心游戏资产,强化呈现)

现状 18 属性色已定义,但**只在 badge/小色块用**。游戏感升级的核心:**让属性色成为卡片的视觉主角**——顶色条加粗、hover 时整卡泛属性色光晕。

```css
/* 新增:属性色光晕变量(每个属性卡片 hover 时触发) */
--type-glow-grass: rgba(93, 190, 98, 0.15);
--type-glow-fire: rgba(240, 131, 46, 0.15);
/* ... 18 个属性各一个 glow 变量 */
```

#### 新增:稀有度/阶段 渐变色(游戏进度感)

```css
/* 稀有度渐变(替代当前的纯色 badge) */
--rarity-common: linear-gradient(135deg, #9ca3af, #6b7280);
--rarity-rare: linear-gradient(135deg, #3b82f6, #2563eb);
--rarity-epic: linear-gradient(135deg, #8b5cf6, #7c3aed);
--rarity-legend: linear-gradient(135deg, #f59e0b, #d97706);
```

### 2.2 字体策略

skill 推荐 Fira Code/Sans(技术工具感),但 SpiritDex 已用 **Geist**(现代无衬线,中文 fallback 好)。**保留 Geist 作正文**,新增一个**展示型字体用于标题/数字**(强化图鉴感):

```css
/* 标题/编号:用带性格的字体(建议 LXGW WenKai 霞鹜文楷,中文游戏感强,免费) */
--font-display: "LXGW WenKai", "Geist", system-ui;
/* 正文:维持 Geist */
--font-body: "Geist", system-ui;
/* 数字/编号:等宽,强化"图鉴编号"感 */
--font-mono: "Geist Mono", ui-monospace;
```

> 备选:若不想引入中文字体,标题直接用 Geist Bold + 更大字号 + 字间距收紧,也能强化识别。

### 2.3 间距/圆角/阴影(游戏化升级)

```css
:root {
  /* 圆角:统一为 2xl(1rem),游戏 UI 偏圆润 */
  --radius-sm: 0.5rem;
  --radius-md: 0.75rem;
  --radius-card: 1rem;  /* 全站卡片统一 */

  /* 阴影:新增"浮起"层次(游戏卡片悬浮感) */
  --shadow-card: 0 1px 3px rgba(0,0,0,0.06);
  --shadow-hover: 0 12px 28px rgba(0,0,0,0.12); /* 加大浮起 */
  --shadow-glow: 0 0 0 1px var(--primary), 0 8px 24px var(--primary-glow); /* 选中态光晕 */
}
```

## 三、组件范式升级

### 3.1 卡片系统(游戏图鉴卡)

**核心升级**:所有列表卡片统一为"**图鉴卡**"范式,强化收集感。

```
┌─────────────────────────┐
│ ▓▓▓▓ 属性色顶条(加粗)▓▓▓▓ │  ← hover 时整卡泛属性色光晕
│   ┌─────────┐           │
│   │  立绘   │  No.0001  │  ← 编号用 mono 字体,图鉴感
│   │  /图标  │  ⭐ 二阶   │  ← 阶段/稀有度用渐变 badge
│   └─────────┘           │
│   精灵名(展示字体)       │
│   [草][毒] 属性 chip     │
└─────────────────────────┘
```

**游戏感细节**:
- hover:卡片上浮 + 属性色光晕(`box-shadow: var(--shadow-hover) + 属性glow`)
- 立绘区:背景用属性色的极淡渐变(当前是灰底 `bg-surface-2`,改为 `linear-gradient(属性色 5% → 透明)`)
- 已收藏的卡片:右上角小心心 + 边框泛金(收集成就感)

### 3.2 导航(分组 + 进度感)

现状:4 分组下拉(图鉴/知识/工具/AI)。游戏感升级:

- **Logo 区**:精灵球图标 hover 时旋转一圈(微交互,趣味)
- **分组下拉**:每组配主题色(已有),下拉项 hover 时图标做小幅弹跳(120ms)
- **新增:图鉴进度条**(可选,后期):header 右侧显示"已收录 671/700",进度条用渐变,激发收集欲

### 3.3 按钮系统(统一变体)

当前按钮散落手写。收敛为 4 种变体,带游戏感:

| 变体 | 用途 | 视觉 |
|------|------|------|
| `primary` | 主 CTA | 精灵球红 + hover 光晕 |
| `secondary` | 次要 | 属性色填充(可传 color prop) |
| `outline` | 取消/返回 | 描边 + hover 填充浅色 |
| `ghost` | 图标按钮 | 透明 + hover 背景 |

### 3.4 Badge 系统(渐变化)

上一轮已收敛到 CSS 变量。本轮升级为**渐变 badge**(稀有度/阶段用渐变,普通分类保持纯色),强化"品质感"。

## 四、页面架构规范

### 4.1 容器宽度阶梯(统一)

```
列表页(图鉴/技能/道具...):  max-w-7xl (数据密集,多列)
详情页(精灵/文章...):       max-w-5xl (单列+侧栏)
文章阅读:                   max-w-3xl (阅读舒适)
AI 对话:                    max-w-3xl (聚焦)
工具页(计算器...):          max-w-4xl (表单+结果)
```

统一为一个常量,消除当前 7 国乱:
```ts
// lib/layout.ts
export const WIDTH = {
  list: "max-w-7xl",
  detail: "max-w-5xl",
  article: "max-w-3xl",
  tool: "max-w-4xl",
} as const;
```

### 4.2 页面骨架规范(统一 PageHeader)

所有内页统一用 `<PageHeader>` 组件(当前三套样式收敛):

```
[← 返回链接]
页面标题(展示字体)     [右侧操作区:筛选/收藏]
副标题/统计数据
```

### 4.3 首页(英雄区强化游戏感)

当前英雄区已不错。游戏感升级:
- 背景:加极淡的精灵球纹样( radial-gradient 圆点阵已有,可换成精灵球轮廓 SVG 水印)
- 御三家展示:从普通卡片改为"**精选展柜**"——更大立绘 + 属性光晕 + "开始你的旅程"引导
- 新增:**今日推荐/AI 精灵推荐**区块(若 AI 启用),强化"活的图鉴"感

### 4.4 精灵详情页(图鉴感巅峰)

这是最能体现游戏感的页面,重点升级:
- **大立绘区**:属性色径向渐变背景 + 立绘轻微浮动动画
- **种族值雷达图**:强化——属性色描边 + 极值高亮
- **收藏按钮**:爱心点击时粒子散开动画(收集仪式感)
- **进化链**:横向时间轴,当前阶段高亮发光

## 五、动效规范(游戏化微交互)

skill 推荐:时长 150-300ms,缓动 `power1/2.out`。

| 场景 | 动效 | 时长 |
|------|------|------|
| 卡片 hover | 上浮 4px + 属性色光晕渐入 | 200ms ease-out |
| 按钮 hover | 背景渐变 + 轻微缩放 1.02 | 150ms |
| 页面切换 | 内容淡入上移(不滑入,避免晕) | 200ms |
| 列表加载 | 骨架屏脉冲(已有 .skeleton) | 1.4s 循环 |
| 收藏点击 | 爱心放大 + 粒子散开 | 300ms |
| 立绘展示 | 轻微上下浮动(呼吸感) | 3s infinite |

**约束**:所有动效包 `@media (prefers-reduced-motion: reduce)` 降级。

## 六、迁移路径(分阶段,低风险)

### 阶段 1:设计令牌升级(1-2 文件,影响全局但安全)

- 首页英雄区 + 御三家展柜
